## [좌측 1/3] 서론 · 방법

### 문제
- AI 에이전트가 메일·주소록·캘린더에 접근해 자율 업무 수행
- 통제 수단 두 가지: **프롬프트 지시**("최소한만 읽어라") vs **인터페이스 projection**(도구가 필요한 필드만 반환)
- 어느 쪽이 실제로 민감 전달을 줄이는가? — 분리 비교한 실증 부족

### 사전 등록 2×2 설계
| | projection 없음 | task-aware projection |
|---|---|---|
| **중립 프롬프트** | A | C |
| **최소화 지시** | B | D |

- primary: **A vs C**, endpoint `safe_completion`(민감 전달 0 ∧ 업무 성공) — 분석 전 동결
- 합성 워크스페이스 55항목 (민감 notes·인젝션 본문 5건 포함)

### 품질 게이트 (이 연구의 방법론 기여)
1. **시나리오 라벨**: 2인 독립 검토 + 자동 게이트 — "도구 0회 호출 에이전트" 통과율 **0%** 강제 (승인 43 / 폐기 5)
2. **모델 파일럿**: tool-call 형식 준수 ≥80%만 채택 — `mistral:7b`(0%)·`qwen2.5:14b`(12%) 제외. "전달 0"이 프라이버시가 아니라 **형식 미준수**인 오염을 차단
3. 4모델 × 43시나리오 × 4조건 = **688 runs, 기술 실패 0**, 전 모델 동일 설정(manifest 해시 동결)

## [중앙 1/3] 결과 — 3계층을 합치지 않는다

**그림: `fig_v3_layers.png` (중앙 상단 크게)**

### ① 전달 계층 — projection이 민감 전달을 제거
| 조건 | run당 민감 전달 |
|---|---:|
| A 중립 | 0.50 |
| B 지시 | 0.52 |
| C projection | **0.00** |
| D 둘 다 | **0.00** |

**A−C 차이 0.50 (95% CI 0.35~0.65)** — 4모델(qwen2.5 3b/7b·qwen3 8b·llama3.1 8b) 전 계열 동일 방향 (`fig_v3_by_model.png`)

### ② 프롬프트 축 — 지시는 전달을 못 줄임
중립 0.50 vs 지시 0.52. llama3.1은 지시 조건에서 오히려 **0.58→0.72**.
(v2와 달리 진짜 "유무" 대조 — 이번엔 말할 수 있다)

### ③ 엔드포인트 — 정직 보고
`safe_completion`: A 0.01 / B 0.00 / C **0.04** / D 0.03
A/B는 업무에 성공해도 민감 필드가 딸려 나가 safe가 아니었다.
**primary A vs C: McNemar p=0.070 — 유의하지 않음.** 업무 성공 자체가 3~6%로 드물어 검정력 부족. "안전한 완수 증가"는 미입증으로 남긴다.

## [우측 1/3] 고찰 · 결론

### 결론
> 민감정보 통제는 모델에게 **부탁**하는 문제가 아니라 인터페이스가 무엇을 **반환**할지 설계하는 문제다. 필드 projection은 모델 교체와 무관하게 전달을 0으로 만들었고, 프롬프트 지시는 아무것도 바꾸지 못했다.

### 왜 primary가 유의하지 않았나 (숨기지 않음)
- 기저 task 성공률 3~6% → "안전한 성공"의 차이를 검출할 표본 부족
- 원인은 소형 모델 능력 vs 엄격한 validator가 겹침 — 느슨한 validator는 v2에서 측정 자체를 무너뜨렸으므로 선택하지 않았다

### 한계
- 인젝션 차단은 설계 수준(전달 가능 5→0건)만 — 행동 수준은 clean/poisoned 공격쌍 후속 실험
- 소형 로컬 4모델·합성 데이터 — 상용 대형 모델 미검증
- seed 1 결정 실행 (분산은 43시나리오 축으로)

### 향후 연구
1. clean/poisoned 공격쌍으로 인젝션 행동 차단 측정
2. task 성공률 원인 분해(사람 채점 대조) 후 primary 재검정
3. 상용·대형 모델 확장

### 재현성 (하단 배너)
사전 등록 프로토콜 `protocols/v3_protocol.json` · 라벨 게이트 `validate_review_v3.py` (exit 0) · 원시 로그 `experiments/main-*/runs.jsonl`(원문 없음, 해시·카운트만) · 계측 테스트 135개 통과 — **GitHub: jaepaly/2026CORE**
